A comunidade [freeCodeCamp.org](https://freecodecamp.org) é possível graças a milhares de voluntários gentis como você. Se você quiser contribuir com seu tempo e experiência, teremos o prazer de recebê-lo.

:::nota
Antes de prosseguir, reserve 2 minutos para ler nosso [Código de Conduta](https://www.freecodecamp.org/code-of-conduct). Nós o aplicamos rigorosamente em toda a nossa comunidade para que contribuir com o freeCodeCamp.org seja uma experiência segura e inclusiva para todos.

:::

Você está convidado a criar, atualizar e corrigir bugs em nosso [currículo](#currículo), nos ajudar a corrigir bugs na [plataforma de aprendizagem](#plataforma-de-aprendizagem) do freeCodeCamp.org ou [nos ajudar a traduzir](#traduções) o freeCodeCamp.org para outros idiomas.

Respondemos às perguntas mais comuns sobre contribuições [em nossas Perguntas Frequentes para Colaboradores](/faq/).

Boas contribuições.

## Currículo

Nosso currículo é selecionado pela comunidade global do freeCodeCamp. Dessa forma, podemos incorporar o conhecimento especializado de voluntários como você.

Você pode ajudar a expandir e aprimorar o currículo. Você também pode atualizar histórias de usuários do projeto para explicar melhor os conceitos. E você pode aprimorar nossos testes automatizados para que possamos testar o código das pessoas com mais precisão.

**Se você tem interesse em aprimorar nosso currículo, veja aqui [como contribuir para o currículo](/como-trabalhar-em-desafios-de-codificação/).**

**Se você tem interesse em traduzir, aqui está [como traduzir os recursos do freeCodeCamp](/how-to-translate-files/).**

## Plataforma de Aprendizagem

Nossa plataforma de aprendizagem é executada em uma pilha JavaScript moderna. Ela possui vários componentes, ferramentas e bibliotecas, incluindo Node.js, MongoDB, OAuth 2.0, React, Gatsby, Webpack e muito mais.

De modo geral, temos um servidor de API baseado em Node.js, um conjunto de aplicativos cliente baseados em React, scripts de teste para avaliar os projetos curriculares enviados pelos participantes e muito mais. Se você deseja contribuir produtivamente para a plataforma de aprendizagem, recomendamos que se familiarize com essas ferramentas.

**Se você quiser nos ajudar a melhorar nossa base de código, veja [como configurar o freeCodeCamp](/how-to-setup-freecodecamp-locally/).**
